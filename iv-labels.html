IV Label Generator

Create a pharmacy IV label from the fields below, or load this page with a pre-filled URL.

**Not for Protected Health Information**

This page can be driven entirely from its URL:
/iv-labels/<site>/<drug name>/<RXNORM code>/<#hex color>/<WxL in inches>/
Example: /iv-labels/801/dilTIAZem//#FFFFFF/0.93x3/ (leave a segment blank between slashes to skip it).
Drug name is case-sensitive and takes precedence over the RXNORM code; if drug name is left blank, the RXNORM code is looked up against the RxNorm API to fill it in.
